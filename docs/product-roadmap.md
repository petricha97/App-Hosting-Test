# Product Roadmap

## Must-Have
These are the features needed for a strong first real event management product.

- authentication split between organizers and applicants/attendees
- organization settings
  - company name
  - headline / description
  - logo
- IAM / users and access
  - owner
  - invited internal users
  - roles
  - permission groups
- event creation and editing
- event publish / unpublish
- public event pages
  - default
  - custom
  - redirect
- registration forms
- form templates
- response / submission management
- attendee/applicant portal
  - applied events
  - upcoming events
  - registration status
- registration controls
  - registration period
  - capacity
  - registration open / closed
- email confirmations and reminders

## Should-Have
These make the product much more complete and competitive.

- event-specific responses page
- exports
  - CSV / spreadsheet
- attendee management
  - approve / reject
  - waitlist
  - internal notes
- check-in flow
- QR / ticket confirmation
- reusable event page templates
- analytics
  - registrations over time
  - conversion
  - attendance summary
- discount / promo support
- invoice / receipt support
- better scheduling
  - sessions
  - tracks
  - speakers
  - venues

## Nice-to-Have
These are strong differentiators or later-stage features.

- ticketing / payments
- refund handling
- sponsorship sections
- media galleries
- AI-assisted page generation
- AI-assisted event setup
- conditional form logic
- file upload fields
- audit logs
- SSO / enterprise auth
- CRM / email / calendar integrations
- branded workspaces / white-labeling
- multi-org advanced governance

## Suggested Build Order
1. responses and attendee management
2. IAM / users and access
3. applicant / attendee portal
4. organization settings
5. registration controls and emails
6. check-in flow
7. analytics and exports
8. payments / advanced enterprise features

## Meeting Summary
- `Must-have`: auth split, IAM, org settings, events, pages, forms, templates, responses, attendee portal, registration controls, emails
- `Should-have`: attendee ops, exports, check-in, analytics, better scheduling, promos
- `Nice-to-have`: payments, AI generation, advanced CMS, audit logs, SSO, integrations
