Always add comments to every function and every new file explaining what it does.

**Why:** User wants to be able to read and understand the code easily in future sessions without needing to ask.

**How to apply:** Write a file-level comment at the top of every new file describing its purpose. Write a function-level comment above every exported (and non-trivial internal) function explaining what it does, its parameters, and what it returns. Keep comments factual and concise — one to three lines is usually enough per function.
